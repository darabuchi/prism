# 业务逻辑层

## 说明

包含所有业务逻辑实现，按功能模块划分。

## 子模块

### subscription/ - 订阅管理
- 订阅的增删改查
- 订阅内容获取
- 订阅解析
- 自动更新

### node/ - 节点管理
- 节点的增删改查
- 节点测试（延迟、速度、解锁）
- 节点选择策略
- 熔断器管理
- 评分算法

### route/ - 路由引擎
- 路由规则管理
- 规则匹配（域名、IP、CIDR）
- Trie 树优化
- 规则优先级

### proxy/ - 代理核心
- 代理隧道
- 会话管理
- 连接池
- 黑名单管理

### task/ - 任务管理
- 任务队列
- Worker 管理
- 任务调度
- 失败重试

## 使用原则

1. 每个子模块独立
2. 通过接口交互
3. 避免循环依赖
4. 单元测试覆盖
