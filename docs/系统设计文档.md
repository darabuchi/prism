### 1.2 核心模块职责

#### 1.2.1 订阅管理模块 (Subscription Manager)

**职责**:
- 订阅的增删改查操作
- 定期自动更新订阅内容
- 解析多种订阅格式(Clash YAML, V2Ray链接等)
- 订阅流量统计和到期管理
- 失败重试和自动禁用逻辑

**关键类/接口**:
```go
type SubscriptionManager interface {
    Add(url string, proxyType ProxyType) (*Subscription, error)
    Update(id string, force bool) error
    Delete(id string) error
    List(filter SubscriptionFilter) ([]*Subscription, error)
    Parse(content []byte, format Format) ([]*Node, error)
}
```

#### 1.2.2 节点管理模块 (Node Manager)

**职责**:
- 节点的注册、存储和索引
- 节点状态维护(存活/禁用/熔断状态)
- 活动节点池管理(默认Top 10)
- 节点评分计算和排序
- 节点启用/禁用逻辑

**关键类/接口**:
```go
type NodeManager interface {
    Register(node *Node) error
    UpdateStatus(id string, status NodeStatus) error
    GetActiveNodes(limit int) ([]*Node, error)
    CalculateScore(node *Node) float64
    ReloadActivePool() error
}
```

#### 1.2.3 测试调度模块 (Test Scheduler)

**职责**:
- 延迟测试调度和执行
- 速度测试调度和执行
- 解锁检测调度和执行
- 地理位置检测
- 路由质量分析
- 测试结果持久化

**关键类/接口**:
```go
type TestScheduler interface {
    ScheduleDelayTest(nodeID string, interval time.Duration) error
    ScheduleSpeedTest(nodeID string) error
    ScheduleUnlockTest(nodeID string, service ServiceType) error
    ExecuteTest(test *TestTask) (*TestResult, error)
}
```

#### 1.2.4 路由引擎模块 (Routing Engine)

**职责**:
- 规则匹配和路由决策
- Domain Trie 快速查找
- IP CIDR 范围匹配
- 进程和路径匹配
- 地理路由
- 自定义规则管理

**关键类/接口**:
```go
type RoutingEngine interface {
    Match(metadata *ConnectionMetadata) (*Rule, TargetType, error)
    AddRule(rule *Rule) error
    RemoveRule(ruleID string) error
    Reload() error
}
```

#### 1.2.5 代理隧道模块 (Proxy Tunnel)

**职责**:
- 管理混合端口(HTTP+SOCKS5)
- TUN 接口管理
- 连接拦截和路由
- 会话持久化
- 连接统计和事件发射

**关键类/接口**:
```go
type ProxyTunnel interface {
    Start() error
    Stop() error
    HandleConnection(conn net.Conn) error
    GetStatistics() *ProxyStatistics
}
```

#### 1.2.6 MITM 拦截器模块 (MITM Interceptor)

**职责**:
- HTTPS 流量解密
- 动态证书生成和缓存
- 请求/响应拦截
- JavaScript 脚本执行
- MITM 规则匹配

**关键类/接口**:
```go
type MITMInterceptor interface {
    InterceptRequest(req *http.Request, script *Script) (*http.Request, error)
    InterceptResponse(resp *http.Response, script *Script) (*http.Response, error)
    GenerateCertificate(domain string) (*tls.Certificate, error)
    ExecuteScript(ctx *ScriptContext, script string) (interface{}, error)
}
```

#### 1.2.7 节点选择器模块 (Node Selector)

**职责**:
- 实现多种选择策略(Sticky, RandomRange, Range等)
- 应用前置/后置过滤器
- 熔断器集成
- 会话阻止列表管理
- 优雅降级和回退

**关键类/接口**:
```go
type NodeSelector interface {
    Select(session *Session, filters []Filter) (*Node, error)
    ApplyStrategy(strategy Strategy, nodes []*Node) (*Node, error)
}
```

#### 1.2.8 场景识别模块 (Scene Recognition) - 新增

**职责**:
- 基于域名/IP自动识别应用场景
- 内置场景库(流媒体/AI/游戏/办公等)
- 用户自定义场景规则
- 场景与路由策略的关联
- 场景使用统计和推荐

**关键类/接口**:
```go
type SceneRecognizer interface {
    Recognize(metadata *ConnectionMetadata) (*Scene, error)
    RegisterScene(scene *Scene) error
    GetSceneRules(sceneType SceneType) ([]*Rule, error)
    GetRecommendedStrategy(scene *Scene) (*RoutingStrategy, error)
}
```

#### 1.2.9 成本管理模块 (Cost Manager) - 新增

**职责**:
- 订阅流量消耗跟踪
- 订阅成本计算和分配
- 流量预测和告警
- 成本优化建议
- 使用报告生成

**关键类/接口**:
```go
type CostManager interface {
    TrackUsage(subscriptionID string, bytes int64) error
    CalculateCost(subscriptionID string, period Period) (*Cost, error)
    PredictUsage(subscriptionID string, days int) (*UsagePrediction, error)
    GetOptimizationSuggestions() ([]*Suggestion, error)
}
```

#### 1.2.10 监控告警模块 (Monitor & Alert) - 新增

**职责**:
- 节点健康度监控
- 订阅到期提醒
- 流量超额告警
- 性能异常检测
- 多渠道通知(邮件/推送/Webhook)

**关键类/接口**:
```go
type MonitorService interface {
    MonitorNodeHealth(nodeID string) (*HealthStatus, error)
    CheckSubscriptionExpiration() ([]*Alert, error)
    DetectAnomalies() ([]*Anomaly, error)
    SendAlert(alert *Alert, channels []NotificationChannel) error

```

#### 1.2.11 AI 推荐模块 (AI Recommender) - 新增

**职责**:
- 基于历史使用模式推荐节点

- 路由策略自动调优
- 个性化配置建议

**关键类/接口**:
```go
type AIRecommender interface {
```

### 1.3 数据流图

#### 1.3.1 订阅更新数据流

```
用户触发订阅更新
       ↓
API Layer 接收请求
       ↓
Subscription Manager 创建更新任务
       ↓
Task Queue 排队(高优先级)
       ↓
Worker 从队列获取任务
       ↓
HTTP Client 获取订阅内容
       ↓
Parser 解析订阅格式
       ↓
Node Manager 注册/更新节点
       ↓
Database 持久化节点数据
       ↓
Test Scheduler 为新节点排队延迟测试
       ↓
WebSocket 发送更新事件到前端
       ↓
前端刷新订阅列表和节点列表
```

#### 1.3.2 代理连接建立数据流

```
应用发起网络请求
       ↓
OS 网络栈捕获(TUN) 或 应用配置代理(HTTP/SOCKS5)
       ↓
Proxy Tunnel 接收连接
       ↓
提取元数据(目标域名/IP/端口/进程名)
       ↓
Routing Engine 匹配规则
       ↓
确定目标类型(Direct/Reject/Proxy/Service)
       ↓
如果是 Direct: 直连
如果是 Reject: 拒绝连接
如果是 Proxy: 继续节点选择流程
       ↓
Node Selector 应用选择策略
       ↓
检查会话缓存(Sticky)
       ↓
应用前置过滤器(熔断器/阻止列表)
       ↓
选择最优节点(Range/RandomRange)
       ↓
应用后置过滤器(解锁检查/国家匹配)
       ↓
通过选定节点建立代理连接
       ↓
双向流式数据传输
       ↓
记录流量统计
       ↓
更新熔断器状态
       ↓
连接关闭后清理资源
```

#### 1.3.3 MITM 拦截数据流

```
客户端发起 HTTPS 请求
       ↓
Proxy Tunnel 检测到 HTTPS CONNECT
       ↓
MITM Interceptor 检查域名是否在拦截规则中
       ↓
如果不拦截: 直接转发
如果拦截: 继续 MITM 流程
       ↓
检查证书缓存
       ↓
如果未缓存: 使用 CA 签发域名证书
       ↓
与客户端建立 TLS 连接(使用动态证书)
       ↓
解密 HTTPS 请求
       ↓
执行请求脚本(如果配置)
       ↓
修改请求头/请求体/URL(可选)
       ↓
转发到目标服务器(或代理节点)
       ↓
接收服务器响应
       ↓
执行响应脚本(如果配置)
       ↓
修改响应头/响应体(可选)
       ↓
加密并返回客户端
       ↓
记录 MITM 日志(可选)
```

#### 1.3.4 节点评分更新数据流

```
节点测试完成(延迟/速度/解锁/地理/路由)
       ↓
Test Scheduler 持久化测试结果
       ↓
触发评分重新计算事件
       ↓
Node Manager 获取节点所有测试数据
       ↓
Scoring Engine 应用评分算法
       ↓
计算基础评分(延迟+速度)
       ↓
应用协议奖励(SS/Trojan/VMess)
       ↓
应用解锁奖励(OpenAI/Netflix/YouTube/Disney)
       ↓
应用地理奖励(入口/出口差异)
       ↓
应用路由质量奖励
       ↓
应用惩罚(CN出口/死亡节点)
       ↓
更新节点评分到数据库
       ↓
触发活动节点池重载
       ↓
Node Manager 重新查询 Top N 节点
       ↓
更新内存中的活动节点列表
       ↓
WebSocket 发送节点更新事件到前端
```

## 二、数据库设计

### 2.1 数据库选型

- **主数据库**: SQLite (默认) / MySQL (企业版) / PostgreSQL (企业版)
- **缓存系统**: LevelDB (默认) / Memory / BBolt / Redis

**数据库对比**:

| 特性 | SQLite | MySQL | PostgreSQL |
|------|--------|-------|------------|
| 部署复杂度 | 极低(嵌入式) | 中等 | 中等 |
| 并发性能 | 低(写锁) | 高 | 高 |
| 事务支持 | ACID | ACID | ACID |
| JSON支持 | 基础 | 良好 | 优秀(JSONB) |
| 全文搜索 | FTS5 | FULLTEXT | 强大(tsvector) |
| 地理数据 | 扩展 | 支持 | PostGIS(强大) |
| 复制 | - | 主从/组复制 | 流复制/逻辑复制 |
| 分区表 | - | 支持 | 强大 |
| 扩展性 | 低 | 中 | 高 |
| 适用场景 | 个人/测试 | 企业/高并发 | 企业/复杂查询 |

**选型建议**:
- **SQLite**: 个人用户、桌面应用、测试环境
- **MySQL**: 企业级、高并发读写、云数据库兼容性
- **PostgreSQL**: 复杂查询、JSON密集型、地理数据分析、高级特性需求

**缓存系统对比**:

| 特性 | Memory | BBolt | Redis | LevelDB |
|------|--------|-------|-------|---------|
| 持久化 | 否 | 是 | 可选 | 是 |
| 分布式 | 否 | 否 | 是 | 否 |
| 性能 | 极高 | 高 | 高 | 高 |
| 内存占用 | 高 | 低 | 中 | 低 |
| 数据结构 | Map | KV | 丰富 | KV |
| 事务支持 | 否 | 是 | 有限 | 是 |
| 跨进程 | 否 | 否 | 是 | 否 |
| 部署复杂度 | 极低 | 极低 | 中 | 低 |
| 适用场景 | 单机/临时 | 单机/持久化 | 分布式/共享 | 单机/嵌入式 |

**缓存选型建议**:
- **LevelDB** (推荐): 单机部署、需要持久化、性能优秀、Google技术栈
- **Memory**: 单机部署、重启可接受数据丢失、追求极致性能
- **BBolt**: 单机部署、需要持久化、事务支持、纯 Go 实现
- **Redis**: 分布式部署、多实例共享缓存、丰富数据结构需求

### 2.2 表结构设计

**说明**: 以下 SQL 语法兼容 MySQL/PostgreSQL，SQLite 需要适当调整(如 `BIGINT` → `INTEGER`, `TINYINT` → `INTEGER`)

#### 2.2.1 订阅表 (subscriptions)

#### 2.3.2 Memory 缓存实现

```go
type MemoryCache struct {
    data    sync.Map
    ttl     sync.Map  // key → expireTime
    maxSize int
    size    int64
    mu      sync.RWMutex
}

func NewMemoryCache(config *CacheConfig) *MemoryCache {
    mc := &MemoryCache{
        maxSize: config.MaxSize,
    }

    // 定期清理过期数据
    go mc.cleanupExpired()

    return mc
}

func (mc *MemoryCache) Get(key string) ([]byte, error) {
    // 检查是否过期
    if expireTime, ok := mc.ttl.Load(key); ok {
        if time.Now().After(expireTime.(time.Time)) {
            mc.Delete(key)
            return nil, ErrNotFound
        }
    }

    value, ok := mc.data.Load(key)
    if !ok {
        return nil, ErrNotFound
    }

    return value.([]byte), nil
}

func (mc *MemoryCache) Set(key string, value []byte, ttl time.Duration) error {
    mc.data.Store(key, value)

    if ttl > 0 {
        mc.ttl.Store(key, time.Now().Add(ttl))
    }

    atomic.AddInt64(&mc.size, int64(len(value)))

    // 检查内存限制
    if mc.maxSize > 0 && atomic.LoadInt64(&mc.size) > int64(mc.maxSize) {
        mc.evictOldest()
    }

    return nil
}
```

#### 2.3.3 BBolt 缓存实现

```go
type BBoltCache struct {
    db         *bbolt.DB
    bucketName []byte
}

func NewBBoltCache(config *CacheConfig) (*BBoltCache, error) {
    db, err := bbolt.Open(config.Path, 0600, nil)
    if err != nil {
        return nil, err
    }

    // 创建 bucket
    err = db.Update(func(tx *bbolt.Tx) error {
        _, err := tx.CreateBucketIfNotExists([]byte("cache"))
        return err
    })

    return &BBoltCache{
        db:         db,
        bucketName: []byte("cache"),
    }, nil
}

func (bc *BBoltCache) Get(key string) ([]byte, error) {
    var value []byte

    err := bc.db.View(func(tx *bbolt.Tx) error {
        bucket := tx.Bucket(bc.bucketName)
        if bucket == nil {
            return ErrBucketNotFound
        }

        data := bucket.Get([]byte(key))
        if data == nil {
            return ErrNotFound
        }

        // 检查 TTL
        var entry CacheEntry
        if err := json.Unmarshal(data, &entry); err != nil {
            return err
        }

        if entry.ExpireAt > 0 && time.Now().Unix() > entry.ExpireAt {
            return ErrNotFound
        }

        value = entry.Value
        return nil
    })

    return value, err
}
```

#### 2.3.4 Redis 缓存实现

```go
type RedisCache struct {
    client *redis.Client
    prefix string
}

func NewRedisCache(config *CacheConfig) (*RedisCache, error) {
    client := redis.NewClient(&redis.Options{
        Addr:     fmt.Sprintf("%s:%d", config.Host, config.Port),
        Password: config.Password,
        DB:       config.DB,
    })

    // 测试连接
    ctx := context.Background()
    if err := client.Ping(ctx).Err(); err != nil {
        return nil, err
    }

    return &RedisCache{
        client: client,
        prefix: config.Prefix,
    }, nil
}

func (rc *RedisCache) Get(key string) ([]byte, error) {
    ctx := context.Background()
    fullKey := rc.prefix + key

    value, err := rc.client.Get(ctx, fullKey).Bytes()
    if err == redis.Nil {
        return nil, ErrNotFound
    }

    return value, err
}

func (rc *RedisCache) Set(key string, value []byte, ttl time.Duration) error {
    ctx := context.Background()
    fullKey := rc.prefix + key

    return rc.client.Set(ctx, fullKey, value, ttl).Err()
}
```

#### 2.3.5 LevelDB 缓存实现

```go
type LevelDBCache struct {
    db *leveldb.DB
}

func NewLevelDBCache(config *CacheConfig) (*LevelDBCache, error) {
    db, err := leveldb.OpenFile(config.Path, nil)
    if err != nil {
        return nil, err
    }

    return &LevelDBCache{db: db}, nil
}

func (lc *LevelDBCache) Get(key string) ([]byte, error) {
    data, err := lc.db.Get([]byte(key), nil)
    if err == leveldb.ErrNotFound {
        return nil, ErrNotFound
    }

    if err != nil {
        return nil, err
    }

    // 检查 TTL
    var entry CacheEntry
    if err := json.Unmarshal(data, &entry); err != nil {
        return nil, err
    }

    if entry.ExpireAt > 0 && time.Now().Unix() > entry.ExpireAt {
        lc.db.Delete([]byte(key), nil)
        return nil, ErrNotFound
    }

    return entry.Value, nil
}

func (lc *LevelDBCache) Set(key string, value []byte, ttl time.Duration) error {
    expireAt := int64(0)
    if ttl > 0 {
        expireAt = time.Now().Add(ttl).Unix()
    }

    entry := CacheEntry{
        Value:    value,
        ExpireAt: expireAt,
    }

    data, err := json.Marshal(entry)
    if err != nil {
        return err
    }

    return lc.db.Put([]byte(key), data, nil)
}
```

**复合索引**:

### 2.7 数据库连接配置

```go
// 数据库抽象层
type Database interface {
    Connect(config *DBConfig) error
    Close() error
    Query(query string, args ...interface{}) (*sql.Rows, error)
    Exec(query string, args ...interface{}) (sql.Result, error)
    Begin() (*sql.Tx, error)
}

// 配置结构
type DBConfig struct {
    Type     string  // sqlite, mysql, postgres
    Host     string
    Port     int
    Name     string
    User     string
    Password string
    SSLMode  string  // for PostgreSQL
    Charset  string  // for MySQL

    // 连接池配置
    MaxOpenConns    int
    MaxIdleConns    int
    ConnMaxLifetime time.Duration
}

// PostgreSQL 连接示例
func NewPostgresDB(config *DBConfig) (*sql.DB, error) {
    dsn := fmt.Sprintf(
        "host=%s port=%d user=%s password=%s dbname=%s sslmode=%s",
        config.Host,
        config.Port,
        config.User,
        config.Password,
        config.Name,
        config.SSLMode, // disable, require, verify-ca, verify-full
    )

    db, err := sql.Open("postgres", dsn)
    if err != nil {
        return nil, err
    }

    db.SetMaxOpenConns(config.MaxOpenConns)
    db.SetMaxIdleConns(config.MaxIdleConns)
    db.SetConnMaxLifetime(config.ConnMaxLifetime)

    return db, nil
}

// MySQL 连接示例
func NewMySQLDB(config *DBConfig) (*sql.DB, error) {
    dsn := fmt.Sprintf(
        "%s:%s@tcp(%s:%d)/%s?charset=%s&parseTime=true&loc=Local",
        config.User,
        config.Password,
        config.Host,
        config.Port,
        config.Name,
        config.Charset,
    )

    db, err := sql.Open("mysql", dsn)
    if err != nil {
        return nil, err
    }

    db.SetMaxOpenConns(config.MaxOpenConns)
    db.SetMaxIdleConns(config.MaxIdleConns)
    db.SetConnMaxLifetime(config.ConnMaxLifetime)

    return db, nil
}

// SQLite 连接示例
func NewSQLiteDB(path string) (*sql.DB, error) {
    db, err := sql.Open("sqlite3", path+"?_journal_mode=WAL&_synchronous=NORMAL")
    if err != nil {
        return nil, err
    }

    // SQLite 不需要连接池配置
    db.SetMaxOpenConns(1)  // 单写连接

    return db, nil
}
```

### 4.1 节点评分算法

#### 4.1.1 评分公式

```go
func CalculateNodeScore(node *Node) float64 {
    score := 0.0

    // 1. 延迟得分(主要因素,满分10分)
    if node.DelayAvg > 0 {
        delayScore := (1 - float64(node.DelayAvg)/10000.0) * 10.0
        if delayScore < 0 {
            delayScore = 0
        }
        score += delayScore
    }

    // 2. 速度得分(显著因素,50MB/s = 1分)
    if node.DownloadSpeed > 0 {
        speedScore := float64(node.DownloadSpeed) / (50 * 1024 * 1024)
        score += speedScore
    }

    // 3. 协议类型奖励
    switch node.Type {
    case "ss":
        score += 3.0  // Shadowsocks 最快
    case "trojan":
        score += 2.0  // Trojan 平衡
    case "vmess":
        score += 1.0  // VMess 功能丰富
    }

    // 4. 解锁能力奖励(每个服务 0.025 分)
    unlockBonus := 0.0
    if node.UnlockOpenAI == 3 {
        unlockBonus += 0.025
    }
    if node.UnlockNetflix == 3 {
        unlockBonus += 0.025
    }
    if node.UnlockYouTube == 3 {
        unlockBonus += 0.025
    }
    if node.UnlockDisney == 3 {
        unlockBonus += 0.025
    }
    score += unlockBonus

    // 5. 地理路由奖励
    if node.InboundCountry != "" && node.OutboundCountry != "" {
        if node.InboundCountry != node.OutboundCountry {
            score += 0.005  // 入口/出口不同,更好的路由多样性
        } else {
            score += 0.0025 // 入口/出口相同
        }
    }

    // 6. 路由质量奖励(显著)
    if node.RouteQuality {
        score += 3.0  // 高质量路由路径
    }

    // 7. 中国出口惩罚
    if node.OutboundCountry == "CN" {
        score -= 10.0
    }

    // 8. 中国入口奖励
    if node.InboundCountry == "CN" {
        score += 3.0
    }

    // 9. 死亡节点惩罚
    if !node.Alive {
        score -= 100.0  // 实际排除死节点
    }

    return score
}
```

### 4.2 节点选择算法

#### 4.2.1 选择流程

```
开始选择节点
    ↓
1. 应用前置过滤器
    ├─ BlockSession: 排除会话阻止列表中的节点
    └─ BeforeRequest: 熔断器检查
    ↓
2. 执行选择策略(按顺序尝试)
    ├─ Sticky 策略
    │   ├─ 检查会话缓存
    │   ├─ 应用该策略的过滤器(Unlock/TotalRequest)
    │   └─ 返回缓存节点或穿透到下一策略
    │
    ├─ RandomRange 策略
    │   ├─ 随机起始位置遍历节点
    │   ├─ 应用该策略的过滤器(Country/Unlock)
    │   └─ 返回第一个通过的节点
    │
    └─ Range 策略(回退)
        ├─ 按评分降序遍历
        └─ 返回评分最高的可用节点
    ↓
3. 应用后置过滤器
    └─ Country: 验证地理匹配
    ↓
4. 返回选定节点或降级
    ├─ 成功: 返回节点
    └─ 失败: 尝试 Direct 连接
```

#### 4.2.2 熔断器算法

```go
type CircuitBreaker struct {
    State              string  // "open"(健康) / "half_open"(探测) / "closed"(不健康)
    TotalRequests      int
    SuccessRequests    int
    ConsecutiveFailures int
    WindowStart        time.Time
}

func (cb *CircuitBreaker) Before() bool {
    now := time.Now()

    // 5分钟滚动窗口
    if now.Sub(cb.WindowStart) > 5*time.Minute {
        cb.Reset()
    }

    switch cb.State {
    case "open":
        // 健康状态,检查是否需要关闭
        if cb.ShouldClose() {
            cb.State = "closed"
            return false  // 拒绝请求
        }
        return true  // 允许请求

    case "half_open":
        // 探测状态,允许有限请求
        return rand.Float64() < 0.5

    case "closed":
        // 不健康状态,偶尔探测
        if rand.Float64() < 0.1 {
            cb.State = "half_open"
            return true  // 探测请求
        }
        return false  // 拒绝请求
    }

    return false
}

func (cb *CircuitBreaker) ShouldClose() bool {
    // 连续失败超过3次
    if cb.ConsecutiveFailures >= 3 {
        return true
    }

    // 基于请求量的动态阈值
    if cb.TotalRequests >= 20 && cb.TotalRequests < 50 {
        return float64(cb.SuccessRequests)/float64(cb.TotalRequests) < 0.6
    } else if cb.TotalRequests >= 50 && cb.TotalRequests < 100 {
        return float64(cb.SuccessRequests)/float64(cb.TotalRequests) < 0.7
    } else if cb.TotalRequests >= 100 {
        return float64(cb.SuccessRequests)/float64(cb.TotalRequests) < 0.8
    }

    return false
}

func (cb *CircuitBreaker) After(success bool) {
    cb.TotalRequests++

    if success {
        cb.SuccessRequests++
        cb.ConsecutiveFailures = 0

        // 从 half_open 恢复到 open
        if cb.State == "half_open" && cb.SuccessRequests >= 3 {
            cb.State = "open"
        }
    } else {
        cb.ConsecutiveFailures++

        // 触发关闭
        if cb.ShouldClose() {
            cb.State = "closed"
        }
    }
}
```

```go
func (sr *SceneRecognizer) Recognize(metadata *ConnectionMetadata) (*Scene, error) {
    // 1. 精确域名匹配
    if scene, ok := sr.domainTrie.LookupExact(metadata.Domain); ok {
        return scene, nil
    }

    // 2. 域名后缀匹配
    if scene, ok := sr.domainTrie.LookupSuffix(metadata.Domain); ok {

    if metadata.IP != "" {

            if scene.MatchIP(metadata.IP) {
                return scene, nil
            }
        }
    }

    // 4. 启发式识别(基于端口/协议)
    scene := sr.HeuristicRecognize(metadata)

    return scene, nil
}
```

### 4.4 流量预测算法 - 新增

#### 4.4.1 线性回归预测

```go
func PredictUsage(subscriptionID string, days int) (*UsagePrediction, error) {
    // 1. 获取历史数据(最近30天)
    records, err := db.GetCostRecords(subscriptionID, 30)
    if err != nil {
        return nil, err
    }

    if len(records) < 7 {
        return nil, errors.New("insufficient data for prediction")
    }

    // 2. 计算每日平均流量
    var totalBytes int64
    for _, record := range records {
        totalBytes += record.TotalBytes
    }
    avgBytesPerDay := totalBytes / int64(len(records))

    // 3. 线性回归拟合趋势
    slope, intercept := LinearRegression(records)

    // 4. 预测未来流量
    predictedBytes := int64(0)
    for i := 1; i <= days; i++ {
        dayValue := float64(len(records) + i)
        predictedBytes += int64(slope*dayValue + intercept)
    }

    // 5. 计算置信区间(简化版)
    stdDev := CalculateStdDev(records, slope, intercept)
    confidenceInterval := stdDev * 1.96  // 95% 置信区间

    return &UsagePrediction{
        PredictedBytes:     predictedBytes,
        ConfidenceInterval: confidenceInterval,
        Trend:              slope,  // 正数表示增长,负数表示下降
    }, nil
}

func LinearRegression(records []*CostRecord) (slope, intercept float64) {
    n := float64(len(records))
    var sumX, sumY, sumXY, sumX2 float64

    for i, record := range records {
        x := float64(i)
        y := float64(record.TotalBytes)
        sumX += x
        sumY += y
        sumXY += x * y
        sumX2 += x * x
    }

    slope = (n*sumXY - sumX*sumY) / (n*sumX2 - sumX*sumX)
    intercept = (sumY - slope*sumX) / n

    return slope, intercept
}
```

```go
func GenerateCACertificate() (*tls.Certificate, error) {
    // 1. 生成 RSA 2048 位私钥
    privateKey, err := rsa.GenerateKey(rand.Reader, 2048)
    if err != nil {
        return nil, err
    }

    // 2. 创建证书模板
    template := &x509.Certificate{
        SerialNumber: big.NewInt(1),
        Subject: pkix.Name{
            CommonName:   "Prism CA",
            Organization: []string{"Prism"},
        },
        NotBefore:             time.Now(),
        NotAfter:              time.Now().AddDate(10, 0, 0),  // 10年有效期
        KeyUsage:              x509.KeyUsageCertSign | x509.KeyUsageDigitalSignature,
        ExtKeyUsage:           []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
        BasicConstraintsValid: true,
        IsCA:                  true,
    }

    // 3. 自签名
    certDER, err := x509.CreateCertificate(rand.Reader, template, template, &privateKey.PublicKey, privateKey)
    if err != nil {
        return nil, err
    }

    // 4. 保存到文件
    certPEM := pem.EncodeToMemory(&pem.Block{Type: "CERTIFICATE", Bytes: certDER})
    keyPEM := pem.EncodeToMemory(&pem.Block{Type: "RSA PRIVATE KEY", Bytes: x509.MarshalPKCS1PrivateKey(privateKey)})

    ioutil.WriteFile(filepath.Join(configDir, "ca.crt"), certPEM, 0644)
    ioutil.WriteFile(filepath.Join(configDir, "ca.key"), keyPEM, 0600)

    // 5. 返回 tls.Certificate
    return &tls.Certificate{
        Certificate: [][]byte{certDER},
        PrivateKey:  privateKey,
    }, nil
}
```

```go
func GenerateDomainCertificate(domain string, caCert *tls.Certificate) (*tls.Certificate, error) {
    // 1. 检查缓存
    if cert, ok := certCache.Get(domain); ok {
        return cert, nil
    }

    // 2. 生成私钥
    privateKey, err := rsa.GenerateKey(rand.Reader, 2048)
    if err != nil {
        return nil, err
    }

    // 3. 解析 CA 证书
    caParsed, err := x509.ParseCertificate(caCert.Certificate[0])
    if err != nil {
        return nil, err
    }

    // 4. 创建证书模板
    template := &x509.Certificate{
        SerialNumber: big.NewInt(time.Now().UnixNano()),
        Subject: pkix.Name{
            CommonName: domain,
        },
        DNSNames:    []string{domain},  // SAN
        NotBefore:   time.Now(),
        NotAfter:    time.Now().AddDate(1, 0, 0),  // 1年有效期
        KeyUsage:    x509.KeyUsageDigitalSignature | x509.KeyUsageKeyEncipherment,
        ExtKeyUsage: []x509.ExtKeyUsage{x509.ExtKeyUsageServerAuth},
    }

    // 5. 使用 CA 签发
    certDER, err := x509.CreateCertificate(rand.Reader, template, caParsed, &privateKey.PublicKey, caCert.PrivateKey)
    if err != nil {
        return nil, err
    }

    // 6. 构建 tls.Certificate
    cert := &tls.Certificate{
        Certificate: [][]byte{certDER, caCert.Certificate[0]},  // 包含证书链
        PrivateKey:  privateKey,
    }

    // 7. 缓存
    certCache.Set(domain, cert, time.Hour*24)

    return cert, nil
}
```
