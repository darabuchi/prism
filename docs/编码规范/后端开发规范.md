# 后端开发规范

## 1. 项目依赖包

### 1.1 LRPC 中间件
项目使用 LRPC 框架作为核心 RPC 框架，必须使用以下中间件：

```go
import (
    "github.com/lazygophers/lrpc/middleware/storage/db"    // 数据库中间件
    "github.com/lazygophers/lrpc/middleware/xerror"        // 错误处理中间件
    "github.com/lazygophers/lrpc/middleware/i18n"          // 国际化中间件
    "github.com/lazygophers/lrpc/middleware/core"          // 核心中间件
)
```

**说明**：
- `db`: 统一的数据库访问层，支持 SQLite/MySQL/PostgreSQL
- `xerror`: 标准化的错误处理和错误码管理
- `i18n`: 多语言支持，响应消息国际化
- `core`: 核心功能（日志、追踪、上下文等）

### 1.2 工具包
使用 lazygophers 提供的标准工具包：

```go
import (
    "github.com/lazygophers/log"                    // 日志处理
    "github.com/lazygophers/utils/candy"            // 工具函数
    "github.com/lazygophers/utils/json"             // JSON 处理
    "github.com/lazygophers/utils/xtime"            // 时间处理
    "github.com/lazygophers/utils/validator"        // 数据验证
    "github.com/lazygophers/utils/cryptox"          // 加密工具
    "github.com/lazygophers/utils/app"              // 应用工具
    "github.com/lazygophers/utils/wait"             // 等待/同步工具
    "github.com/lazygophers/utils/runtime"          // 运行时工具
    "github.com/lazygophers/utils/config"           // 配置管理
)
```

**禁止使用的包**：
- ❌ 禁止使用 `encoding/json`，必须使用 `github.com/lazygophers/utils/json`
- ❌ 禁止使用 `log` 标准库，必须使用 `github.com/lazygophers/log`
- ❌ 禁止使用第三方日志库（如 logrus、zap），统一使用 lazygophers/log

## 3. 错误处理规范

### 3.1 使用 xerror 中间件
所有错误必须使用 `xerror` 包处理：

```go
import "github.com/lazygophers/lrpc/middleware/xerror"

// 返回标准错误
func GetUser(id int64) (*User, error) {
    if id <= 0 {
        return nil, xerror.New(xerror.CodeInvalidParameter, "invalid user id")
    }

    user, err := db.FindUserByID(id)
    if err != nil {
        return nil, xerror.Wrap(err, "failed to find user")
    }

    return user, nil
}
```

### 3.2 错误码规范
使用 xerror 定义的标准错误码：

```go
const (
    CodeSuccess           = 0     // 成功
    CodeInvalidParameter  = 1001  // 参数错误
    CodeUnauthorized      = 1002  // 未授权
    CodeForbidden         = 1003  // 禁止访问
    CodeNotFound          = 1004  // 资源不存在
    CodeInternalError     = 2001  // 内部错误
    CodeDatabaseError     = 2002  // 数据库错误
    CodeExternalError     = 2003  // 外部服务错误
)
```

### 3.3 错误日志
```go
import "github.com/lazygophers/log"

// 记录错误日志
if err != nil {
    log.Error("failed to process",
        log.String("operation", "createUser"),
        log.Error(err),
        log.Int64("user_id", userID))
    return xerror.Wrap(err, "failed to create user")
}
```

## 4. 日志规范

### 4.1 日志级别
使用 lazygophers/log 提供的日志级别：

```go
import "github.com/lazygophers/log"

log.Debug("debug message")              // 调试信息
log.Info("info message")                // 一般信息
log.Warn("warning message")             // 警告信息
log.Error("error message")              // 错误信息
log.Fatal("fatal message")              // 致命错误（会退出程序）
```

### 4.2 结构化日志
使用字段记录结构化信息：

```go
log.Info("user created",
    log.String("username", user.Name),
    log.Int64("user_id", user.ID),
    log.Time("created_at", user.CreatedAt))

log.Error("database query failed",
    log.String("query", sql),
    log.Error(err),
    log.Duration("duration", elapsed))
```

### 4.3 日志字段类型
```go
log.String(key, value)              // 字符串
log.Int(key, value)                 // 整数
log.Int64(key, value)               // 64位整数
log.Float64(key, value)             // 浮点数
log.Bool(key, value)                // 布尔值
log.Time(key, value)                // 时间
log.Duration(key, value)            // 时长
log.Error(err)                      // 错误对象
log.Any(key, value)                 // 任意类型
```

## 5. JSON 处理规范

### 5.1 使用 lazygophers/utils/json
禁止使用 `encoding/json`，必须使用工具包：

```go
import "github.com/lazygophers/utils/json"

// 序列化
data, err := json.Marshal(obj)
if err != nil {
    return xerror.Wrap(err, "failed to marshal")
}

// 反序列化
var obj MyStruct
err := json.Unmarshal(data, &obj)
if err != nil {
    return xerror.Wrap(err, "failed to unmarshal")
}

// 美化输出
pretty, err := json.MarshalIndent(obj, "", "  ")
```

### 5.2 JSON 标签规范
使用 snake_case 命名：

```go
type User struct {
    ID        int64     `json:"id"`
    UserName  string    `json:"user_name"`    // ✅ snake_case
    CreatedAt time.Time `json:"created_at"`
    IsEnabled bool      `json:"is_enabled"`
}

// ❌ 错误示例
type User struct {
    ID        int64     `json:"id"`
    UserName  string    `json:"userName"`     // ❌ camelCase
    CreatedAt time.Time `json:"CreatedAt"`    // ❌ PascalCase
}
```

## 9. 并发处理规范

### 9.1 使用 wait 工具包
```go
import "github.com/lazygophers/utils/wait"

// 等待所有任务完成
var wg wait.Group
for _, item := range items {
    wg.Go(func() error {
        return processItem(item)
    })
}
if err := wg.Wait(); err != nil {
    log.Error("failed to process items", log.Error(err))
}

// 超时控制
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()

if err := wait.Until(ctx, func() error {
    return doSomething()
}, time.Second); err != nil {
    log.Error("operation timeout", log.Error(err))
}
```

## 10. 上下文处理规范

### 10.1 Context 传递
所有需要取消/超时的操作必须接收 context.Context：

```go
func ProcessRequest(ctx context.Context, req *Request) error {
    // 检查 context 是否已取消
    select {
    case <-ctx.Done():
        return ctx.Err()
    default:
    }

    // 业务逻辑...
    return nil
}
```

### 10.2 Context 值传递
```go
// 设置值
ctx = context.WithValue(ctx, "user_id", userID)

// 获取值
userID, ok := ctx.Value("user_id").(int64)
if !ok {
    return xerror.New(xerror.CodeUnauthorized, "user not found")
}
```

## 11. 数据库访问规范

### 11.1 使用 db 中间件
```go
import "github.com/lazygophers/lrpc/middleware/storage/db"

// 查询单条记录
var user User
err := db.Get(ctx, &user, "SELECT * FROM users WHERE id = ?", userID)
if err != nil {
    if db.IsNotFound(err) {
        return nil, xerror.New(xerror.CodeNotFound, "user not found")
    }
    return nil, xerror.Wrap(err, "failed to get user")
}

// 查询多条记录
var users []User
err := db.Select(ctx, &users, "SELECT * FROM users WHERE enabled = ?", true)

// 执行写操作
result, err := db.Exec(ctx, "UPDATE users SET name = ? WHERE id = ?", name, id)
```

### 11.2 事务处理
```go
tx, err := db.Begin(ctx)
if err != nil {
    return xerror.Wrap(err, "failed to begin transaction")
}
defer tx.Rollback()

// 执行事务操作
_, err = tx.Exec("INSERT INTO users (...) VALUES (...)")
if err != nil {
    return xerror.Wrap(err, "failed to insert user")
}

// 提交事务
if err := tx.Commit(); err != nil {
    return xerror.Wrap(err, "failed to commit transaction")
}
```

## 13. 代码风格规范

### 13.1 命名规范
- 变量名：驼峰命名（camelCase）
- 常量名：大写字母 + 下划线（UPPER_CASE）
- 函数名：驼峰命名（camelCase），导出函数首字母大写
- 类型名：帕斯卡命名（PascalCase）

### 13.2 注释规范
```go
// Package repository provides data access layer.
package repository

// User represents a user in the system.
type User struct {
    ID   int64  // User ID
    Name string // User name
}

// CreateUser creates a new user in the database.
// It returns the created user ID and an error if any.
func CreateUser(ctx context.Context, user *User) (int64, error) {
    // Implementation...
}
```

### 13.3 错误处理
```go
// ✅ 正确：检查并处理错误
result, err := doSomething()
if err != nil {
    return xerror.Wrap(err, "failed to do something")
}

// ❌ 错误：忽略错误
result, _ := doSomething()
```

## 14. 性能优化规范

### 14.1 避免不必要的分配
```go
// ✅ 使用 strings.Builder
var builder strings.Builder
for _, s := range strs {
    builder.WriteString(s)
}
result := builder.String()

// ❌ 使用 += 拼接字符串
result := ""
for _, s := range strs {
    result += s  // 每次都会分配新内存
}
```

### 14.2 使用对象池
```go
import "sync"

var bufferPool = sync.Pool{
    New: func() interface{} {
        return new(bytes.Buffer)
    },
}

func processData(data []byte) {
    buf := bufferPool.Get().(*bytes.Buffer)
    defer bufferPool.Put(buf)
    buf.Reset()

    // 使用 buf...
}
```

## 15. 测试规范

### 15.1 单元测试
```go
func TestCreateUser(t *testing.T) {
    ctx := context.Background()

    user := &User{
        Name:  "test",
        Email: "test@example.com",
    }

    id, err := CreateUser(ctx, user)
    if err != nil {
        t.Fatalf("CreateUser failed: %v", err)
    }

    if id <= 0 {
        t.Errorf("expected positive id, got %d", id)
    }
}
```

### 15.2 表驱动测试
```go
func TestValidateEmail(t *testing.T) {
    tests := []struct {
        name    string
        email   string
        wantErr bool
    }{
        {"valid email", "test@example.com", false},
        {"invalid email", "invalid", true},
        {"empty email", "", true},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            err := ValidateEmail(tt.email)
            if (err != nil) != tt.wantErr {
                t.Errorf("ValidateEmail() error = %v, wantErr %v", err, tt.wantErr)
            }
        })
    }
}
```
