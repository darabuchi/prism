## 二、目录说明

### 2.1 核心目录

#### cmd/
**用途**: 应用程序入口点（只包含 main.go 文件）

**文件说明**:
- `main.go`: 主程序入口，使用 cobra 实现子命令

**子命令设计**:
```go
// 使用 cobra 实现多个子命令
prism                    # 根命令
├── server              # 启动服务器
│   ├── --config       # 配置文件路径
│   ├── --port         # HTTP 端口
│   └── --daemon       # 后台运行
├── subscription        # 订阅管理
│   ├── list           # 列出所有订阅
│   ├── add            # 添加订阅
│   ├── update         # 更新订阅
│   └── remove         # 删除订阅
├── node               # 节点管理
│   ├── list           # 列出所有节点
│   └── test           # 测试节点
├── config             # 配置管理
│   ├── show           # 显示配置
│   └── validate       # 验证配置
└── version            # 显示版本信息
```

**设计原则**:
- 单文件入口，通过 cobra 管理所有子命令
- 保持简洁，主要逻辑在 internal 中
- 只负责程序初始化和命令分发
- 提供友好的命令行交互体验

**构建示例**:
```bash
# 构建单一可执行文件
go build -o bin/prism ./cmd/main.go

# 或使用 Makefile
make build
```

**使用示例**:
```bash
# 启动服务器
./bin/prism server --config ./configs/config.yaml

# 列出订阅
./bin/prism subscription list

# 添加订阅
./bin/prism subscription add --url https://example.com/sub

# 测试节点
./bin/prism node test --id 123
```

#### shared/
**用途**: 前端共享代码（Web 和 Desktop 共用）

**包含内容**:
- **types/**: TypeScript 类型定义（订阅、节点、配置等）
- **utils/**: 通用工具函数（格式化、验证、存储等）
- **constants/**: 常量定义（API 端点、配置常量等）

**设计原则**:
- 平台无关，不依赖特定框架特性
- 使用 TypeScript 编写，提供完整类型定义
- 可以被 Web 和 Desktop 项目直接引用
- 通过 package.json 作为本地 npm 包使用

**引用方式**:
```json

    "@prism/shared": "workspace:*"

```

**功能模块**:

### 2.2 业务层目录

#### internal/state/
**职责**: 全局状态管理（参考 fire 项目设计）

**核心文件**:
- `state.go`: 全局状态管理器，提供统一的状态访问接口
- `config.go`: 配置管理（加载 YAML、验证、热更新）
- `cache.go`: 缓存管理（初始化缓存、提供缓存实例）
- `table.go`: 数据库表管理（Model 注册、自动迁移）
- `queue.go`: 任务队列管理
- `i18n.go`: 国际化支持

**全局状态示例**:
```go
// State 全局状态
var State struct {
    Config     *Config        // 配置
    Db         func() *lrpc.DB // 数据库连接
    Cache      Cache          // 缓存实例
    Queue      *Queue         // 任务队列

    // 数据库表 Model
    Subscription *db.Model[prism.ModelSubscription]
    Node         *db.Model[prism.ModelNode]
    Route        *db.Model[prism.ModelRoute]
}

// 初始化
func Init() error {
    // 加载配置
    if err := loadConfig(); err != nil {
        return err
    }

    // 初始化数据库
    if err := initDB(); err != nil {
        return err
    }

    // 初始化缓存
    if err := initCache(); err != nil {
        return err
    }

    // 注册表
    registerTables()

    return nil
}
```

#### internal/ 业务包

## 三、代码组织原则

### 3.1 包命名规范

```go
// ✅ 好的包名
package cache
package service
package handler

// ❌ 差的包名
package cacheUtil
package serviceImpl
package handlerPackage
```

### 3.2 文件命名规范

```
功能.go          # 主实现
功能_test.go     # 单元测试
```

示例:
```
cache/
├── cache.go          # 缓存接口
├── memory.go         # 内存实现
├── memory_test.go    # 内存测试
├── leveldb.go        # LevelDB 实现
```

### 3.3 依赖方向

```
┌──────────────────────────────────────────┐
│              前端层                       │
│  ┌──────────┬──────────┬──────────┐     │
│  │   web/   │  desktop │  mobile  │     │
│  │          │          │  (可选)  │     │
│  └────┬─────┴─────┬────┴─────┬────┘     │
│       │           │          │          │
│       └───────────┼──────────┘          │
│                   │                     │
│                   ▼                     │
│            ┌─────────────┐              │
│            │   shared/   │  前端共享代码 │
│            └─────────────┘              │
│                   │                     │
│                   ▼                     │
│            ┌─────────────┐              │
│            │ HTTP API    │              │
│            └─────────────┘              │
└──────────────────┬────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────┐
│              后端层                       │
│  ┌─────────────┐                         │
│  │ cmd/server  │  程序入口               │
│  └──────┬──────┘                         │
│         │                                │
│         ▼                                │
│  ┌─────────────┐                         │
│  │   internal  │  内部实现               │
│  │   ├─ api    │                         │
│  │   ├─ service│                         │
│  │   └─ state  │                         │
│  └──────┬──────┘                         │
│         │                                │
│         ▼                                │
│  ┌─────────────┐                         │
│  │    prism    │  公共类型               │
│  └─────────────┘                         │
│         │                                │
│         ▼                                │
│  ┌─────────────┐                         │
│  │     pkg     │  可复用包               │
│  └─────────────┘                         │
└──────────────────────────────────────────┘
```

**原则**:
- **前端层**:
  - web/ 和 desktop/ 都依赖 shared/ 共享代码
  - 前端通过 HTTP API 与后端通信，不直接依赖后端代码
  - web/ 和 desktop/ 之间相互独立
- **后端层**:
  - 上层可以依赖下层
  - 下层不能依赖上层
  - 同层之间谨慎依赖

### 3.4 循环依赖避免

❌ **错误示例**:
```
service/subscription → service/node
service/node → service/subscription
```

✅ **正确方法**:
1. 提取公共接口到独立包
2. 使用依赖注入
3. 使用事件总线

### 4.1 状态管理（state）

```go
// 全局状态
State.Config          // 配置
State.Db()            // 数据库连接
State.Subscription    // 订阅表 Model
State.Node            // 节点表 Model
```

### 4.2 业务模块

```go
// 订阅管理（internal/subscription）
subscription.Create()     // 创建订阅
subscription.Update()     // 更新订阅
subscription.Fetch()      // 获取订阅内容
subscription.Parse()      // 解析订阅

// 节点管理（internal/node）
node.Test()              // 测试节点
node.Select()            // 选择最优节点
node.UpdateScore()       // 更新评分

// 路由管理（internal/route）
route.Match()            // 匹配路由规则
route.AddRule()          // 添加规则
```

### 4.3 API 层（api）

```go
// 路由注册
router.POST("/api/subscriptions", handler.CreateSubscription)
router.GET("/api/subscriptions/:id", handler.GetSubscription)
router.PUT("/api/subscriptions/:id", handler.UpdateSubscription)
```

## 九、附录：常用命令

### 9.1 项目初始化

```bash
# 创建后端基础目录
mkdir -p cmd internal/{state,cache,service,api} pkg config data logs

# 创建前端目录
mkdir -p web/{frontend,admin} desktop

# 初始化 Go 模块
go mod init github.com/ice-cream-heaven/prism

# 安装 Go 依赖
go mod tidy

# 初始化前端项目（可选）
cd web/frontend && npm create vite@latest . -- --template react-ts
cd ../admin && npm create vite@latest . -- --template react-ts
```

### 9.2 代码检查

```bash
# 格式化
go fmt ./...

# 静态检查
go vet ./...

# Lint 检查
golangci-lint run
```

### 9.3 构建运行

#### 后端

```bash
# 构建服务器
go build -o bin/prism-server ./cmd/server.go

# 构建命令行工具
go build -o bin/prism-cli ./cmd/cli.go

# 运行服务器
./bin/prism-server

# 开发模式（热重载）
air
```

#### 前端

```bash
# 开发模式 - 用户前端
cd web/frontend
npm run dev

# 开发模式 - 管理后台
cd web/admin
npm run dev

# 构建生产版本
npm run build
```

#### 桌面应用

```bash
# 开发模式
cd desktop
npm run dev

# 打包应用
npm run build

# 打包特定平台
npm run build:win   # Windows
npm run build:mac   # macOS
npm run build:linux # Linux
```

#### Docker 部署

```bash
# 构建镜像
docker build -t prism:latest .

# 运行容器
docker run -d \
  -p 8080:8080 \
  -p 1080:1080 \
  -v ./data:/app/data \
  -v ./config:/app/config \
  prism:latest
```
