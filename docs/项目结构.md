## 二、目录说明

### 2.1 核心目录

#### cmd/
**用途**: 应用程序入口点
**原则**:
- 每个可执行程序一个子目录
- 保持简洁，主要逻辑在 internal 中
- 只负责程序初始化和启动

#### prism/
**用途**: 可被外部引用的公共包
**包含**:
- 数据模型定义（ModelSubscription、ModelNode等）
- 错误码定义（ErrCode*）
- 公共常量和类型

**原则**:
- 不包含具体实现
- 只定义接口和类型
- 保持稳定的 API

#### internal/
**用途**: 内部实现，外部无法引用
**优势**:
- 封装实现细节
- 避免 API 滥用
- 允许自由重构

### 2.2 业务层目录

#### internal/state/
**职责**: 全局状态管理
- 配置加载
- 数据库连接
- 日志初始化
- 全局变量管理

#### internal/cache/
**职责**: 缓存系统实现
- 统一缓存接口
- 多后端实现（Memory、LevelDB、BBolt、Redis）
- LRU 淘汰策略
- TTL 过期机制

#### internal/service/
**职责**: 业务逻辑实现
**子模块**:
- `subscription/`: 订阅管理（获取、解析、更新）
- `node/`: 节点管理（测试、选择、熔断）
- `route/`: 路由引擎（规则匹配、Trie树）
- `proxy/`: 代理核心（隧道、会话、连接池）
- `task/`: 任务管理（队列、调度、Worker）

#### internal/api/
**职责**: HTTP API 实现
- 路由配置
- 中间件链
- 请求处理器
- 参数验证
- 响应封装

### 2.3 公共包目录

#### pkg/
**用途**: 可被外部项目引用的公共包
**原则**:
- 高度独立
- 无内部依赖
- 文档完善

**子包**:
- `parser/`: 订阅解析器（Clash、V2Ray、Surge）
- `protocol/`: 协议实现（SOCKS5、HTTP、VMess）

### 2.4 配置和数据

#### config/
配置文件存放目录
- `config.yaml`: 主配置文件
- `config.example.yaml`: 配置模板
- `routes.yaml`: 路由规则

#### data/
运行时数据目录（.gitignore）
- SQLite 数据库文件
- 缓存文件
- 临时文件

#### logs/
日志文件目录（.gitignore）

### 2.5 测试目录

#### tests/
集成测试和专项测试
- `integration/`: 集成测试
- `stress/`: 压力测试
- `testutil/`: 测试工具

**单元测试**: 放在对应包的 `*_test.go` 文件中

### 2.6 部署目录

#### deployments/
部署配置文件
- `docker/`: Docker 相关
- `systemd/`: Systemd 服务
- `kubernetes/`: K8s 配置

## 三、代码组织原则

### 3.1 包命名规范

```go
// ✅ 好的包名
package cache
package service
package handler

// ❌ 差的包名
package cacheUtil
package serviceImpl
package handlerPackage
```

### 3.2 文件命名规范

```
功能.go          # 主实现
功能_test.go     # 单元测试
```

示例:
```
cache/
├── cache.go          # 缓存接口
├── memory.go         # 内存实现
├── memory_test.go    # 内存测试
├── leveldb.go        # LevelDB 实现
└── leveldb_test.go   # LevelDB 测试
```

### 3.3 依赖方向

```
┌─────────────┐
│  cmd/prism  │  程序入口
└──────┬──────┘
       │
       ▼
┌─────────────┐
│   internal  │  内部实现
│   ├─ api    │
│   ├─ service│
│   └─ state  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│    prism    │  公共类型
└─────────────┘
       │
       ▼
┌─────────────┐
│     pkg     │  可复用包
└─────────────┘
```

**原则**:
- 上层可以依赖下层
- 下层不能依赖上层
- 同层之间谨慎依赖

### 3.4 循环依赖避免

❌ **错误示例**:
```
service/subscription → service/node
service/node → service/subscription
```

✅ **正确方法**:
1. 提取公共接口到独立包
2. 使用依赖注入
3. 使用事件总线

## 四、模块职责划分

### 4.1 状态管理（state）

```go
// 全局状态
State.Config          // 配置
State.Db()            // 数据库连接
State.Subscription    // 订阅表 Model
State.Node            // 节点表 Model
```

### 4.2 业务服务（service）

```go
// 订阅服务
subscription.Create()     // 创建订阅
subscription.Update()     // 更新订阅
subscription.Fetch()      // 获取订阅内容
subscription.Parse()      // 解析订阅

// 节点服务
node.Test()              // 测试节点
node.Select()            // 选择节点
node.UpdateScore()       // 更新评分
```

### 4.3 API 层（api）

```go
// 路由注册
router.POST("/api/subscriptions", handler.CreateSubscription)
router.GET("/api/subscriptions/:id", handler.GetSubscription)
router.PUT("/api/subscriptions/:id", handler.UpdateSubscription)
```

## 五、文件内容组织

```go
// 1. Package 声明
package service

// 2. Import 分组
import (
    // 标准库
    "context"
    "fmt"

    // 第三方库

    // 本项目

const (
    DefaultTimeout = 30

var (
    ErrNotFound = errors.New("not found")
)

// 5. 类型定义
type Manager struct {
    // fields
}

// 6. 构造函数
func NewManager() *Manager {
    return &Manager{}
}

// 7. 公共方法
func (m *Manager) PublicMethod() error {
    return nil

// 8. 私有方法
func (m *Manager) privateMethod() {
}

func helperFunction() {
}
```

### 5.2 接口定义位置

```go
// ✅ 在使用方定义接口
package service

type NodeTester interface {
    TestDelay(nodeID uint64) error
}

func NewManager(tester NodeTester) *Manager {
    return &Manager{tester: tester}
}

// ❌ 在实现方定义接口
package tester

type NodeTester interface {
    TestDelay(nodeID uint64) error
}
```

## 六、特殊文件说明

### 6.1 doc.go

用于包级别文档：

```go
// Package cache 提供统一的缓存接口和多种实现。
//
// 支持的缓存后端:
//   - Memory: 内存缓存，使用 LRU 淘汰策略
//   - LevelDB: 持久化 KV 存储
//   - BBolt: 嵌入式事务数据库
//   - Redis: 分布式缓存
//
// 基本用法:
//
//	cache := cache.NewMemoryCache[string](1000)
//	cache.Set("key", "value", 5*time.Minute)
//	val, err := cache.Get("key")
package cache
```

### 6.2 export.go

用于统一导出：

```go
// internal/service/export.go
package service

import (
    "github.com/ice-cream-heaven/prism/internal/service/subscription"
    "github.com/ice-cream-heaven/prism/internal/service/node"
)

// 导出子包的公共接口
var (
    CreateSubscription = subscription.Create
    UpdateSubscription = subscription.Update

    TestNode = node.Test
    SelectNode = node.Select
)
```
