## 文档阅读顺序建议

### 初次阅读
1. 先阅读 [系统设计文档.md](../系统设计文档.md) 了解整体架构
2. 阅读 [数据库访问层](数据库访问层.md) 和 [缓存系统](缓存系统.md) 了解数据层
3. 阅读 [API接口层](API接口层.md) 了解接口设计
4. 根据负责的模块阅读对应的业务逻辑层文档

### 按功能模块阅读
- **订阅功能**: 订阅管理 → 节点管理 → 任务队列
- **代理功能**: 代理核心 → 路由引擎 → 节点管理
- **测试功能**: 节点管理 → 任务队列
- **监控功能**: API接口层 → 错误处理 → 部署与运维

### 按技术栈阅读
- **数据库相关**: 数据库访问层 → 缓存系统 → 并发控制
- **HTTP/API 相关**: API接口层 → 错误处理
- **并发相关**: 并发控制 → 任务队列 → 缓存系统
- **性能相关**: 性能优化 → 缓存系统 → 数据库访问层

## 贡献指南

在更新详细设计文档时，请遵循以下规范：

1. **文档结构**: 每个文档应包含：
   - 文档版本信息
   - 相关文档引用
   - 接口定义（Go 代码）
   - 实现细节（Go 代码 + 注释）
   - 数据流图或序列图（可选）
   - 测试示例

2. **代码示例**:
   - 使用真实的 Go 代码
   - 包含必要的注释
   - 遵循项目编码规范

3. **图表**:
   - 使用 Markdown 代码块绘制 ASCII 图
   - 或使用 Mermaid 语法

4. **版本控制**:
   - 每次更新后更新文档版本信息
   - 记录更新记录

5. **交叉引用**:
   - 在文档中引用其他相关文档
   - 使用相对路径链接
