## 一、概述

并发控制机制确保系统在高并发场景下的数据一致性和性能。

### 设计目标

1. **数据一致性**: 避免并发冲突
2. **性能优化**: 最小化锁竞争
3. **死锁避免**: 合理的锁顺序
4. **资源限制**: 控制并发数量
5. **优雅降级**: 过载保护

## 二、锁策略

### 2.1 sync.Mutex - 互斥锁

**使用场景**: 简单的临界区保护

```go
package service

import (
	"sync"
)

// SubscriptionUpdater 订阅更新器
type SubscriptionUpdater struct {
	mu       sync.Mutex
	updating map[uint64]bool
}

// BeginUpdate 开始更新（防止重复更新）
func (u *SubscriptionUpdater) BeginUpdate(id uint64) bool {
	u.mu.Lock()
	defer u.mu.Unlock()

	if u.updating[id] {
		return false // 已在更新中
	}

	u.updating[id] = true
	return true
}

// EndUpdate 结束更新
func (u *SubscriptionUpdater) EndUpdate(id uint64) {
	u.mu.Lock()
	defer u.mu.Unlock()

	delete(u.updating, id)
}
```

### 2.2 sync.RWMutex - 读写锁

**使用场景**: 读多写少的场景

```go
package cache

import (
	"sync"
)

// RouteCache 路由缓存
type RouteCache struct {
	mu     sync.RWMutex
	routes map[string]*Route
}

// Get 获取路由（读锁）
func (c *RouteCache) Get(domain string) (*Route, bool) {
	c.mu.RLock()
	defer c.mu.RUnlock()

	route, ok := c.routes[domain]
	return route, ok
}

// Set 设置路由（写锁）
func (c *RouteCache) Set(domain string, route *Route) {
	c.mu.Lock()
	defer c.mu.Unlock()

	c.routes[domain] = route
}

// List 列出所有路由（读锁）
func (c *RouteCache) List() []*Route {
	c.mu.RLock()
	defer c.mu.RUnlock()

	routes := make([]*Route, 0, len(c.routes))
	for _, r := range c.routes {
		routes = append(routes, r)
	}
	return routes
}
```

### 2.3 sync.Map - 并发安全Map

**使用场景**: 高并发读写、键值对频繁变化

```go
package service

import (
	"sync"
	"time"
)

// ConnectionPool 连接池
type ConnectionPool struct {
	conns sync.Map // key: nodeID, value: *Connection
}

// Get 获取连接
func (p *ConnectionPool) Get(nodeID uint64) (*Connection, bool) {
	val, ok := p.conns.Load(nodeID)
	if !ok {
		return nil, false
	}
	return val.(*Connection), true
}

// Set 设置连接
func (p *ConnectionPool) Set(nodeID uint64, conn *Connection) {
	p.conns.Store(nodeID, conn)
}

// Delete 删除连接
func (p *ConnectionPool) Delete(nodeID uint64) {
	p.conns.Delete(nodeID)
}

// Range 遍历连接
func (p *ConnectionPool) Range(f func(nodeID uint64, conn *Connection) bool) {
	p.conns.Range(func(key, value interface{}) bool {
		return f(key.(uint64), value.(*Connection))
	})
}

// CloseIdle 关闭空闲连接
func (p *ConnectionPool) CloseIdle(maxIdleTime time.Duration) {
	now := time.Now()
	p.Range(func(nodeID uint64, conn *Connection) bool {
		if now.Sub(conn.LastUsedAt) > maxIdleTime {
			conn.Close()
			p.Delete(nodeID)
		}
		return true
	})
}
```

## 三、并发限制

### 3.1 Semaphore - 信号量

**使用场景**: 限制并发数量

```go
package limiter

import (
	"context"
	"errors"
)

// Semaphore 信号量
type Semaphore struct {
	ch chan struct{}
}

// NewSemaphore 创建信号量
func NewSemaphore(max int) *Semaphore {
	return &Semaphore{
		ch: make(chan struct{}, max),
	}
}

// Acquire 获取信号量
func (s *Semaphore) Acquire() error {
	select {
	case s.ch <- struct{}{}:
		return nil
	default:
		return errors.New("semaphore: max concurrent limit reached")
	}
}

// AcquireWithContext 带超时的获取
func (s *Semaphore) AcquireWithContext(ctx context.Context) error {
	select {
	case s.ch <- struct{}{}:
		return nil
	case <-ctx.Done():
		return ctx.Err()
	}
}

// Release 释放信号量
func (s *Semaphore) Release() {
	<-s.ch
}

// TryAcquire 尝试获取（非阻塞）
func (s *Semaphore) TryAcquire() bool {
	select {
	case s.ch <- struct{}{}:
		return true
	default:
		return false
	}
}
```

**使用示例**:

```go
package service

import (
	"github.com/ice-cream-heaven/prism/internal/limiter"
)

// 节点测速限流器（最多同时测10个节点）
var speedTestSemaphore = limiter.NewSemaphore(10)

// TestNodeSpeed 测试节点速度
func TestNodeSpeed(nodeID uint64) error {
	// 获取信号量
	if err := speedTestSemaphore.Acquire(); err != nil {
		return err
	}
	defer speedTestSemaphore.Release()

	// 执行测速
	return doSpeedTest(nodeID)
}
```

### 3.2 Worker Pool - 工作池

**使用场景**: 批量任务处理

```go
package worker

import (
	"sync"
)

// WorkerPool 工作池
type WorkerPool struct {
	workerCount int
	taskChan    chan Task
	wg          sync.WaitGroup
	stopChan    chan struct{}
}

// Task 任务接口
type Task interface {
	Execute() error
}

// NewWorkerPool 创建工作池
func NewWorkerPool(workerCount int, queueSize int) *WorkerPool {
	return &WorkerPool{
		workerCount: workerCount,
		taskChan:    make(chan Task, queueSize),
		stopChan:    make(chan struct{}),
	}
}

// Start 启动工作池
func (p *WorkerPool) Start() {
	for i := 0; i < p.workerCount; i++ {
		p.wg.Add(1)
		go p.worker()
	}
}

// Submit 提交任务
func (p *WorkerPool) Submit(task Task) bool {
	select {
	case p.taskChan <- task:
		return true
	case <-p.stopChan:
		return false
	default:
		return false // 队列已满
	}
}

// Stop 停止工作池
func (p *WorkerPool) Stop() {
	close(p.stopChan)
	p.wg.Wait()
}

// worker 工作协程
func (p *WorkerPool) worker() {
	defer p.wg.Done()

	for {
		select {
		case task := <-p.taskChan:
			task.Execute()
		case <-p.stopChan:
			// 清空剩余任务
			for {
				select {
				case task := <-p.taskChan:
					task.Execute()
				default:
					return
				}
			}
		}
	}
}
```

## 四、原子操作

### 4.1 sync/atomic

**使用场景**: 简单计数器、标志位

```go
package stats

import (
	"sync/atomic"
)

// Stats 统计信息
type Stats struct {
	totalRequests   uint64
	successRequests uint64
	failedRequests  uint64
}

// IncrTotalRequests 增加总请求数
func (s *Stats) IncrTotalRequests() {
	atomic.AddUint64(&s.totalRequests, 1)
}

// IncrSuccessRequests 增加成功请求数
func (s *Stats) IncrSuccessRequests() {
	atomic.AddUint64(&s.successRequests, 1)
}

// IncrFailedRequests 增加失败请求数
func (s *Stats) IncrFailedRequests() {
	atomic.AddUint64(&s.failedRequests, 1)
}

// GetTotalRequests 获取总请求数
func (s *Stats) GetTotalRequests() uint64 {
	return atomic.LoadUint64(&s.totalRequests)
}

// GetSuccessRate 获取成功率
func (s *Stats) GetSuccessRate() float64 {
	total := atomic.LoadUint64(&s.totalRequests)
	if total == 0 {
		return 0
	}

	success := atomic.LoadUint64(&s.successRequests)
	return float64(success) / float64(total)
}

// Reset 重置统计
func (s *Stats) Reset() {
	atomic.StoreUint64(&s.totalRequests, 0)
	atomic.StoreUint64(&s.successRequests, 0)
	atomic.StoreUint64(&s.failedRequests, 0)
}
```

## 五、Channel 模式

### 5.1 Fan-Out/Fan-In

**使用场景**: 并行处理后聚合结果

```go
package service

import (
	"sync"
)

// TestMultipleNodes 并行测试多个节点
func TestMultipleNodes(nodeIDs []uint64) []*TestResult {
	// Fan-Out: 分发到多个goroutine
	resultChan := make(chan *TestResult, len(nodeIDs))
	var wg sync.WaitGroup

	for _, nodeID := range nodeIDs {
		wg.Add(1)
		go func(id uint64) {
			defer wg.Done()
			result := testNode(id)
			resultChan <- result
		}(nodeID)
	}

	// 关闭channel
	go func() {
		wg.Wait()
		close(resultChan)
	}()

	// Fan-In: 聚合结果
	var results []*TestResult
	for result := range resultChan {
		results = append(results, result)
	}

	return results
}
```

### 5.2 Pipeline

**使用场景**: 流式数据处理

```go
package service

// FetchSubscriptions 获取订阅 -> 解析 -> 保存节点
func FetchSubscriptions(urls []string) error {
	// Stage 1: 获取订阅内容
	contentChan := fetchContents(urls)

	// Stage 2: 解析节点
	nodeChan := parseNodes(contentChan)

	// Stage 3: 保存节点
	return saveNodes(nodeChan)
}

func fetchContents(urls []string) <-chan *Content {
	out := make(chan *Content)
	go func() {
		defer close(out)
		for _, url := range urls {
			content := fetchContent(url)
			out <- content
		}
	}()
	return out
}

func parseNodes(contents <-chan *Content) <-chan *Node {
	out := make(chan *Node)
	go func() {
		defer close(out)
		for content := range contents {
			nodes := parseContent(content)
			for _, node := range nodes {
				out <- node
			}
		}
	}()
	return out
}

func saveNodes(nodes <-chan *Node) error {
	for node := range nodes {
		if err := saveNode(node); err != nil {
			return err
		}
	}
	return nil
}
```

### 6.2 乐观锁

```go
package service

import (
	"github.com/ice-cream-heaven/prism"
	"github.com/ice-cream-heaven/prism/internal/state"
)

// UpdateNodeWithOptimisticLock 使用乐观锁更新节点
func UpdateNodeWithOptimisticLock(nodeID uint64, updateFunc func(*prism.ModelNode) error) error {
	maxRetries := 3

	for i := 0; i < maxRetries; i++ {
		// 1. 读取当前版本
		node, err := state.Node.First("id = ?", nodeID)
		if err != nil {
			return err
		}

		oldUpdatedAt := node.UpdatedAt

		// 2. 应用更新
		if err := updateFunc(node); err != nil {
			return err
		}

		// 3. 使用 WHERE 条件确保版本未变化
		result := state.Db().Exec(
			"UPDATE nodes SET score = ?, updated_at = ? WHERE id = ? AND updated_at = ?",
			node.Score,
			node.UpdatedAt,
			nodeID,
			oldUpdatedAt,
		)

		if result.RowsAffected > 0 {
			return nil // 更新成功
		}

		// 版本冲突，重试
	}

	return errors.New("optimistic lock: max retries exceeded")
}
```

## 七、Context 控制

### 7.1 超时控制

```go
package service

import (
	"context"
	"time"
)

// FetchSubscriptionWithTimeout 带超时的订阅获取
func FetchSubscriptionWithTimeout(url string, timeout time.Duration) (*Subscription, error) {
	ctx, cancel := context.WithTimeout(context.Background(), timeout)
	defer cancel()

	resultChan := make(chan *Subscription, 1)
	errorChan := make(chan error, 1)

	go func() {
		sub, err := fetchSubscription(url)
		if err != nil {
			errorChan <- err
			return
		}
		resultChan <- sub
	}()

	select {
	case sub := <-resultChan:
		return sub, nil
	case err := <-errorChan:
		return nil, err
	case <-ctx.Done():
		return nil, ctx.Err()
	}
}
```

## 八、死锁避免

### 8.1 锁顺序

```go
// ❌ 错误示例：可能死锁
func transfer(from, to *Account, amount int) {
	from.mu.Lock()
	to.mu.Lock()   // 可能与其他goroutine的锁顺序相反
	// ...
	to.mu.Unlock()
	from.mu.Unlock()
}

// ✅ 正确示例：固定锁顺序
func transfer(from, to *Account, amount int) {
	// 按 ID 排序加锁
	if from.ID < to.ID {
		from.mu.Lock()
		defer from.mu.Unlock()
		to.mu.Lock()
		defer to.mu.Unlock()
	} else {
		to.mu.Lock()
		defer to.mu.Unlock()
		from.mu.Lock()
		defer from.mu.Unlock()
	}

	// 转账逻辑
	from.Balance -= amount
	to.Balance += amount
}
```

## 九、总结

### 并发控制工具选择

| 场景 | 推荐工具 | 说明 |
|------|---------|------|
| 简单临界区 | `sync.Mutex` | 性能好，简单直接 |
| 读多写少 | `sync.RWMutex` | 允许多个读锁 |
| 高并发KV | `sync.Map` | 无需手动加锁 |
| 计数器/标志 | `sync/atomic` | 无锁，性能最好 |
| 限制并发数 | Semaphore | 资源池管理 |
| 批量任务 | Worker Pool | 复用goroutine |
| 流式处理 | Channel Pipeline | 解耦、可组合 |

### 最佳实践

1. **避免过度加锁**: 使用原子操作或无锁结构
2. **缩小临界区**: 只保护必要的代码
3. **固定锁顺序**: 避免死锁
4. **使用defer释放锁**: 避免忘记释放
5. **超时控制**: 使用context避免永久阻塞
6. **限制并发数**: 避免资源耗尽
